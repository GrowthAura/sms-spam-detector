      ⚙️ How it was built

      Python · NLP (TF-IDF) · Scikit-learn

      01

      Collect

      9,058 real SMS: UCI Spam Collection + ExAIS corpus (Nigeria), deduped.

      02

      Vectorize

      Word TF-IDF + character TF-IDF — catches tricks like "fr33 m0ney".

      03

      Train

      Balanced logistic regression on an 80/20 split.

      04

      Tune recall

      Threshold set to catch 95% of spam — missing scammers is the real cost.

      05

      Ship

      16,000 weights exported so this page classifies live in JS.

      Datasets: UCI SMS Spam Collection + ExAIS (FUNAAB) · Code & training pipeline in the GitHub repo · Built by Mian Noorullah
