    ⚙️ How it was built

    Python · NLP (TF-IDF) · Scikit-learn

    01

    Collect

    5,572 real SMS from the UCI Spam Collection (13.4% spam).

    02

    Vectorize

    TF-IDF turns words into numbers: rare, spammy words weigh more.

    03

    Train

    Naive Bayes vs Logistic Regression on an 80/20 split.

    04

    Evaluate

    Naive Bayes wins: 97% accuracy, zero false alarms on legit texts.

    05

    Ship

    8,000 word-weights exported so this page classifies live in JS.

    Dataset: SMS Spam Collection, UCI ML Repository · Code & training pipeline in the GitHub repo · Built by Mian Noorullah
